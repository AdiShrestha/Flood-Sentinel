# Flood Sentinel: research rebuild

This repository contains a corrected engine foundation, a forensic audit of the legacy project and a detailed research completion plan. **It is not submission ready. There is no validated flood-performance result, trained research model or operational warning service in this tree.**

Start with [plan.md](plan.md). It contains 33 research-validity findings, the corrected scientific design, M3 resource planning, Software Factory v3.3 integration requirements and P00–P14 implementation contracts for separate Architect/Implementor sessions. [AGENTS.md](AGENTS.md) gives the working rules; [project/methodology.md](project/methodology.md) records the current draft boundaries.

The audit inventoried every supplied legacy regular file outside `.git`: 2,186 files, 5,983 archive members and 921 unique content hashes. Independent checks established that the stored NWM comparison series were generated from USGS observations, expansion SWE was generated by a degree-day recurrence, and all 2,838 primary event onset times were peak dates plus noon. These are forensic findings, not new model results. See [audit observations](project/audit/legacy_observations.json), [source disposition](project/audit/legacy_source_review.md) and [full inventory](project/audit/legacy_inventory.json).

The small [engine](source/flood_sentinel) includes causal TCN/attention, a static-gated recurrent primitive, observed-only masked reconstruction, issue-time availability filtering, interval-aware future labels, train-only normalization, fitted Mahalanobis/robust scoring, genuine persistence and a continuous CUSUM of EWMA-smoothed deviations, and independent ranking/probability metric checks. Legacy checkpoints, generated “observations,” hardcoded metric tables and publication claims are excluded. Input provenance and split identity must still be enforced by the future acquisition/domain pipeline; primitives cannot authenticate their callers.

With Python 3.12 and the audit environment's dependencies available, verify the engineering foundation from this folder:

```sh
python3 -m pytest source/tests -q
python3 factory/run_self_tests.py
```
