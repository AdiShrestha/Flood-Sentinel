# License and attribution boundaries

This migration preserves notices; it does not make a blanket legal or ownership determination.

| Paths/material | Current notice/status | Required before study release |
|---|---|---|
| Supplied factory, bootstrap, templates and factory-history `docs/` | Root proprietary license of Aditya Shrestha, retained unchanged | Rights-holder-approved availability/reuse conditions compatible with chosen venue. |
| Inherited causal encoder/reconstruction-head and EA-LSTM architectural code | Legacy MIT notice preserved in `source/flood_sentinel/LICENSE` | Preserve notice; document actual inherited files/concept modifications. |
| Newly written temporal/preprocessing/scoring/metrics/baseline/reconstruction wrapper/tests and audit/plan additions | No new blanket license was imposed during migration | Rights-holder explicitly chooses scope/license and resolves inherited/new boundaries. |
| Future provider raw/derived datasets and maps | Not acquired for the new study; terms unresolved | Record per-product terms, attribution, redistribution and retrieval rights. |
| Legacy inventories/excerpts/diagnostics | Forensic record, not licensed scientific input data | Review lawful publication/attribution; hashes do not confer rights to underlying bytes. |

The legacy notice names “Flood Sentinel Research Consortium.” Retaining that notice is attribution preservation, not independent confirmation of such an organization or its membership. A future author/affiliation list needs actual human confirmation. Public hosting is distinct from permission to reuse; repository visibility does not supersede these notices.
