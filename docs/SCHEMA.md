# v3.3.0 plan and evidence schema

`project/research_plan.json` names population, license, observational/simulation/fixture origin, cohort/source paths, a provenance manifest, methodology and dependency lock, frozen paths, experiments, comparisons, claims, analyses, release files and policy. Research minima are `min_test_groups: 30`, `min_class_count: 10`, `min_seeds: 5`; fixtures can use smaller test-only support and cannot certify research. Counts do not replace a prospective power/precision calculation.

Research plans require `data_provenance`, a frozen JSON file with `dataset_identifier` (URL or `doi:` identifier), `retrieval_date` (YYYY-MM-DD), `license` matching the plan, `source_records_sha256`, `cohort_sha256`, and `provenance_basis: "author_declared"`. The audit validates date/identity/hash consistency. It cannot verify that the declared acquisition occurred or that observational data are authentic.

Experiments declare a model, integral seed, role, frozen config, evaluation splits, threshold and training policy. A typed `execution_contract` specifies an allowlisted runtime, frozen source entrypoint and supported arguments. Legacy `command` argv is translated through the same launch checks. The local executor is not an OS isolation boundary; file permissions, labels and signing keys share the operator's user.

The cohort CSV contains `sample_id,label,group_id,split,source_ids`; optional `entity_ids,timestamp` support additional leakage/temporal checks. Source records contain `record_id,origin`. Every source ID must exist and match the declared origin. Groups, entities and source records cannot cross splits. Labels must be binary and counts integral.

A producer writes `result.json` and a predictions CSV in its assigned attempt directory. The supervisor writes `execution.json`. Predictions require `sample_id,score` with probabilities in [0,1]; producer labels are optional. The gate joins frozen cohort labels. Optional supplied labels and reported metrics must agree with recomputation. The six metrics are AUROC, average precision, accuracy, F1, Brier and log loss; average precision is distinct from threshold precision.

Learned models supply raw contiguous epoch history with `epoch,train_loss,validation_loss`, initial/selected checkpoints, epoch count and stopping evidence. Fixed budgets require two complete tail windows within a preregistered relative tolerance; early stopping requires the actual validation patience event and its selected checkpoint. These verify a stated procedure, not global optimization or sufficient scientific quality.

Comparisons give aligned experiment pairs, a metric, alpha, minimum effect, precision target and decision rule. `sampling_unit: "test_group"` uses paired group resampling/permutation conditional on the trained models. `sampling_unit: "seed_fixed_test"` additionally requires `inference_scope: "fixed_test_corpus"`; its comparative claims restrict population/scope to that corpus. Seeds cannot support population generalization from a single held-out dataset. Plans reject infeasible exact-test alpha/family resolution before running.

Claims name an exact estimand, population, scope and verified experiment IDs. Reproduction identity binds model/config/training/runtime; relabeling another model is rejected. Amendments disclose prior holdout consumption. Test-driven confirmatory adaptation requires new holdout groups, not just a renamed epoch.

Reviews bind the audit digest and current artifact hashes, have distinct specific reasoning for nine topics, three objections, resolved diagnostics, limitations and venue sources. Identity/mode disclosures are author declarations, not cryptographically verified reviewer independence. The human digest exposes material attempts, amendments and limitations.

Other metric families or causal/topology/efficiency claims require reviewed domain adapters; binary evidence cannot be relabelled to satisfy them.

Each epoch contains `research_plan_snapshot.json`, `freeze.json`, and signed `execution_ledger.json`. The ledger reserves each experiment's attempt before launch and binds its completed execution-record digest. Reservation nonce values are canonical UUID4 strings, unique across retained epochs and equal to the committed execution record. Reserved paths identify the declared experiment's `attempt0001`; pending digests are null and completed digests are lowercase SHA-256. Missing/deleted/replaced evidence blocks against the current ledger. Amendments commit the preceding epoch's file inventory and track held-out sample/source/group identities. These are local consistency checks; restoration of a complete previously signed state requires an external monotonic witness to detect.

Research certificates also bind private `project/release_checks.json` bytes and `validation_sha256` over executable QA scripts/tests. The report records fresh coverage, registered attack, mutation and seeded-fault outcomes with current engine/corpus hashes. Neither certification path trusts a previously stored report instead of running preflight. Failed/stale report or corpus bindings invalidate release handoff; fixture evidence never certifies research.
